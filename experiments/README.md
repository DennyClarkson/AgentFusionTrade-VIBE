# PID mathematical reference

`pid-tick-envelope.html` is an optional offline illustration of the controller. It uses synthetic prices and cannot connect to MT5, send orders or claim strategy performance. `tests/test_pid_visual.cjs` checks its controller against fixed Python reference vectors.

The installable plugin is [FusionPIDTrader](../docs/PID-EA.md), with its own native chart interface and Tick execution. The reference page is not needed to install or operate that EA.
